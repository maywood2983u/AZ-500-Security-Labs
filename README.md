# AZ-500 Azure Security Technologies – Lab Portfolio

This repository contains completed hands-on labs from the **Microsoft AZ-500: Azure Security Technologies** certification path. These labs demonstrate my practical skills in securing Azure environments, managing identity, and implementing real-world threat protection strategies using Microsoft’s cloud security tools.

## 🔒 Objective

To document and showcase applied skills in:
- Identity and access control
- Threat detection and response
- Resource protection
- Just-in-time (JIT) security
- Microsoft Defender for Cloud
- Log Analytics and Azure Monitor

Each lab folder includes:
- A dedicated `README.md` summarizing objectives and key tasks
- Screenshots of my completed work
- (Where applicable) scripts or commands used
